# Proyecto KinalApp
Breve descripcion de lo que hace la aplicacion

## Tecnologia Utilizadas
* **Java 17**
* **Sping boot 4.0.2**
* **Maven**(Gestor de dependencias)
* **MYSQL**(Sistema de gestion de base de datos)

## Requisitos previos
Antes de ejecutar la aplicacion, debe tener instalado:
* JDK 17 o superior
* Maven Instalado
* Una instancia activa en MYSQL

## Instalacion y ejecucion
1. Clonar el repositorio.
2. Abrir el proyecto en un IDE compatible con la aplicación.
3. Abrir la carpeta kinalApp.
4. Abrir la carpeta src.
5. Abrir la carpeta main.
6. Abrir la carpeta java.
7. Abrir el paquete com/wilsontut/kinalapp.
8. Ejecutar la clase principal KinalappApplication.
